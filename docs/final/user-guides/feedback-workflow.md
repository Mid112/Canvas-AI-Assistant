# Feedback Workflow Guide

## Paths

- `/instructor/feedback/create`
- Related assignment/submission contexts from course navigation
- Assistant may draft feedback that hands off into the feedback form

## Flow

1. Choose course / assignment / student submission context as prompted.
2. **Describe** the feedback intent or paste notes.
3. Generate a draft; edit tone and accuracy.
4. **Review / approve** before any Canvas write (comments / feedback posting per implemented action).

## Tips

- Prefer concrete rubric language over generic praise.
- Double-check the student and submission identity on the review step.
- If the assistant drafted the text, you remain responsible for correctness before confirm.
